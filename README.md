# Solenne — gold atelier storefront

A visually led gold-jewellery shop: twelve pieces rendered live in three.js, a stepped configurator
(colour, karat, size, width, finish, engraving) with live pricing from the gold spot price, and a bag and
checkout that save orders to the claude.ai Artifact database.

- Start here: [`CLAUDE.md`](CLAUDE.md) → [`docs/architecture.md`](docs/architecture.md)
- Run: `npm install && npm run dev`
- Build for publishing: `npm run build` → `dist/artifact.html`
